# tinylittleme

Arbeidsnavn. 3D-plattformspill i nettleseren: du er krympet og må komme deg fra gulvet til toppen. På sikt bygges brettet av bilder du tar av rommet ditt.

Status: spillbar prototype med håndlaget brett (nattbord + bokhylle). Se [CONCEPT.md](CONCEPT.md) for beslutninger, arkitektur og plan.

```
npm run serve   # http://localhost:8000
npm test        # fysikktester
npm run solve   # løsbarhetsvalidator
```

Three.js (MIT) ligger i `lib/`.
